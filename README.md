# 復盤記事本/心情記事錄

## Proposal Report

### 動機與目標
<!-- 說明為什麼想做這個專題 -->
日常生活中並非每一天都和昨天一樣，有時可能較晚起，較晚出門，錯過一班公車，得等50分鐘，而又沒腳踏車借，只能走到學校來，此類事情應該層出不窮，如果可以將它們記錄下來，每天晚上看一點，想必生活的品質會有所進步，而同時再附加記事錄的功能，類似日記。
### 預期功能
<!-- 列出預計實作的功能 -->
本系統預計實作以下功能：

基本功能

1.每日事件記錄
    使用者可以新增每日發生的事件,並附上時間，提醒自己下次可以怎改進
    例如： 睡過頭,錯過公車,忘記帶東西,提早完成作業
    
2.記事本功能
    類似日記功能,可輸入文字紀錄每日心得
    
3.時間標記功能
    自動記錄日期與時間,方便日後查詢
    
進階功能

4.事件分類功能
    使用者可分類事件
    例如：遲到,學習,健康,生活
    
5.統計分析功能
    統計某種事件發生次數
    例如：一週遲到幾次,一個月早起幾天
    
6.提醒功能
    每晚提醒使用者紀錄
    例如："今天發生什麼事情呢？"
    
7.搜尋功能
    可搜尋過去記錄
    例如：搜尋「遲到

### 與課程的關聯
本專題與課程中所學之資料結構與演算法概念具有高度關聯。
首先，在資料儲存方面，本系統使用 vector（動態陣列） 來儲存事件紀錄與日記內容，展現了如何在程式中有效地管理與存取資料。
其次，在功能實作上，系統將應用搜尋演算法（如線性搜尋，未來可進一步實作二元搜尋）來讓使用者快速查找特定事件或關鍵字，體現搜尋演算法在實務上的應用。
此外，本專題也會使用排序演算法（例如 C++ 的 sort() 函式）將資料依照時間或事件頻率進行排序，提升資料的可讀性與操作效率。
在進階功能中，系統可透過 map（雜湊表） 進行事件次數的統計分析，例如計算某類事件的發生頻率，這展現了資料結構在統計與資料分析上的應用。
另外，本專題亦涉及 檔案輸入與輸出（File I/O），使資料能夠被長期保存，符合實際應用程式的開發需求。
總體而言，本專題整合了課程中所學的多項核心概念，包括資料結構的設計、搜尋與排序演算法的應用，以及資料處理與儲存技術，並將其應用於實際生活問題中，兼具理論與實務價值。
