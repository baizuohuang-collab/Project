# 復盤記事本/心情記事錄

## Proposal Report

### 動機與目標
<!-- 說明為什麼想做這個專題 -->
日常生活中並非每一天都和昨天一樣，有時可能較晚起，較晚出門，錯過一班公車，得等50分鐘，而又沒腳踏車借，只能走到學校來，此類事情應該層出不窮，如果可以將它們記錄下來，每天晚上看一點，想必生活的品質會有所進步，而同時再附加記事錄的功能，類似日記。
### 預期功能
<!-- 列出預計實作的功能 -->
本系統預計實作以下功能：

基本功能

1.每日事件記錄
    使用者可以新增每日發生的事件,並附上時間，提醒自己下次可以怎改進
    例如： 睡過頭,錯過公車,忘記帶東西,提早完成作業
    
2.記事本功能
    類似日記功能,可輸入文字紀錄每日心得
    
3.時間標記功能
    自動記錄日期與時間,方便日後查詢
    
進階功能

4.事件分類功能
    使用者可分類事件
    例如：遲到,學習,健康,生活
    
5.統計分析功能
    統計某種事件發生次數
    例如：一週遲到幾次,一個月早起幾天
    
6.提醒功能
    每晚提醒使用者紀錄
    例如："今天發生什麼事情呢？"
    
7.搜尋功能
    可搜尋過去記錄
    例如：搜尋「遲到

### 遇到的困難
在使用編輯器VScode時，因為不太熟悉，導致無法順利編譯，經過多次嘗試及研究，發現是沒有另外下載編譯器所導致的，在下載時因為網路問題而導致無法成功安裝編譯器，在多次嘗試及重新開機後才終於可以成功編譯出執行檔，另外在引入GUI編輯Qt時，也因為無法成功產生執行檔而放棄製作GUI。
提醒功能中，用到thread detach導致一直出現視窗跳出，需另做修改。
現在的 id 編號邏輯有點錯誤，會無法找到想刪除的文字，一週的視窗顯示日期是錯誤的，經過修改後目前無法顯示出任何檔案內容。
id 的編號並非無法改變的，在大型一點的專案中應該要用指標來實作，且不應該可以被修改。
在 member function 中的操作都需要重新把檔案輸入到一個陣列上，有點耗費時間、空間，希望想出更好的方法。Hash table 或許可以解決(讓指標以 id 來定)
